### Wake Island Mission Requirements

Missions that run on Wake Island require the following addons:

```json
[
	{
		"modId": "5A78300A9F2D7A65",
		"name": "HMAS Adelaide",
		"version": "1.0.5"
	},
	{
		"modId": "5968980A29FBD58B",
		"name": "Wake Island",
		"version": "1.0.40"
	}
]
```
